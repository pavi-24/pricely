# Pricely - Smart House Price Prediction

An end-to-end Machine Learning powered Android application for estimating property values across major Indian cities (Mumbai, Bengaluru, Delhi NCR, Hyderabad, Chennai, Pune, Kolkata, Ahmedabad).

## Project Details
- **App Name**: Pricely
- **Tagline**: Smart House Price Prediction
- **Package Name / Application ID**: `com.pavithran.pricely`

## Project Structure
```
D:\HousePricePrediction\
```
